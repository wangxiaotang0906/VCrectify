# VCrectify 代码实现与验收报告

截至 2026-09-18，论文框架已实现为可安装的 Python 项目。核心面向 backbone 接口编程，接入了官方 TxPert 架构和独立实现的 SUMMER 方法适配器，使用真实 Replogle K562 essential-gene 数据。当前已经完成本地数值流程及软件集成验收；完整真实 LLM 流程仍等待模型服务地址，按你的要求保持为空。

## 已交付

| 需求 | 实现情况 |
|---|---|
| 框架可替换 backbone | 数值/推理 Protocol、注册工厂、`module:factory` 自定义接入与示例 |
| 论文持续学习方法 | 严格 LOPO、90% 固定阈值、四类裁决、条件均衡 replay、引用驱动知识权重 EMA |
| 默认主动获取 | 一半分歧最高、一半随机；各消融变体独立在线选样 |
| 数据隔离 | 同批预测及引用先封存，再揭示标签；测试集只评估，不影响训练/选样 RNG |
| TxPert | 直接导入官方模型；真实细胞级训练、GAT/Exphormer、单图/多图、checkpoint |
| SUMMER | 双角色摘要、KG 检索、已观察案例、DE→方向两阶段推理、严格引用及 JSON 校验 |
| K562 | 真实 H5AD 分批读取、归一化、重复符号处理、扰动划分、MWU/BH、可追溯数据产物 |
| 工程交付 | CLI、英文/中文 README、框架 SVG、方法与数据文档、CI 配置、许可证、wheel 与源码包 |

## 实际验收

完整测试 **81 项通过**，静态 Python 检查通过。真实 K562 子集为 64 个读出基因、24 个扰动条件、128 个对照细胞和 760 个扰动细胞。初始/候选/验证/测试按 8/8/4/4 固定划分。

官方 TxPert 已完成真实数据上的 4 轮主动获取和持续更新。裁决版、Update-all、Random-correction 分别进行自己的在线选样；数值修正条件数分别为 1、8、1，知识修正条件数为 0、8、0。这里用于数值流程验收的推理器明确标记为诊断模型，不冒充 SUMMER。

真实 TxPert 断点续跑与不中断运行的审计记录、测试预测逐字节一致。另有带 dropout 的模型/优化器/RNG 恢复测试，验证不是只保存了模型参数。

SUMMER 官方资产已核验并导入：覆盖全部 88 个读出或靶基因，共 176 条摘要。其中两个基因的四条 one-hop 摘要为空，显式使用官方 single-node 版本，来源与差异已记录，没有补写虚构生物学摘要。完整框架的 HTTP 集成测试使用明确标记的本地响应 fixture。

Python wheel 已成功构建、在工作区隔离目录安装，并实际执行 demo。源码发布前还在干净 checkout 中通过 75 项测试；另 6 项需要独立安装官方 TxPert 源码的测试按预期跳过。远程 CI 状态见仓库的 Actions 页面。

## 尚未完成的真实运行与科学边界

1. **真实 Qwen3-8B 推理尚未运行。** 正式配置的唯一离线检查缺项是服务地址。填写 `VCRECTIFY_LLM_BASE_URL`，按服务修改 `VCRECTIFY_LLM_MODEL`，密钥通过 `VCRECTIFY_API_KEY` 后可启动。
2. 当前为短训练、小规模工程验收，不是论文表格复现。数值指标并不好，详细值如实记录在[英文验收记录](validation.md)，没有将诊断模型、mock 响应或子集指标作为论文结果。
3. TxPert 短训练输出存在负的 log1p 尺度表达，DES 如实返回空值及原因；没有偷偷裁剪、复制均值伪造细胞。有效细胞分布的 DES 公式已经实现并通过独立测试。
4. 正式实验仍需冻结完整数据划分、训练预算、验证集选定的超参数及多种子协议。精确 LOPO 和反复候选打分计算量较大；当前配置的 LLM 请求上限估计为 14,336 次，尚未扣除缓存，也未包含格式重试。
5. 框架独立代码与第三方模型、资产许可证分别处理。TxPert 和 SUMMER 的官方相关资源包含非商业限制，不能把完整组合统一宣称为不受限制的 Apache 开源。
